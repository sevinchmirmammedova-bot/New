## **Платформа *VK WorkSpace* представила обновление 26.3: в сервисе появились корзина пользователей, передача прав на файлы и расширенный экспорт досок**

**VK WorkSpace** выпустила релиз версии **26.3**, в котором расширила инструменты администрирования, управления файлами и совместной работы на виртуальных досках. Главными нововведениями стали обратимое удаление учетных записей, возможность передавать права на личные папки и выгрузка досок в векторный PDF.

# **Управление аккаунтами в панели администратора**

В панели администрирования появился раздел «Корзина», который делает удаление пользователей обратимым. При переносе аккаунта в корзину данные сотрудника сохраняются во всех сервисах платформы, а администратор может массово восстанавливать или окончательно удалять профили с помощью поиска.
- **Гибкие настройки.** Размер корзины не ограничен, а срок хранения записей задается в конфигурации.
- **Контроль безопасности.** Все операции с корзиной фиксируются в журнале аудита.
- **Особенности работы.** В корзину также попадают аккаунты при импорте из *CSV*, однако удаление через интеграцию с *Active Directory (AD)* в ней не учитывается.

# **Новые возможности Диска VK WorkSpace**
Обновление упростило передачу рабочих материалов при смене сотрудников и расширило функциональность встроенных редакторов.
- **Передача прав владения.** Администратор домена теперь может передать все личные папки и файлы одного пользователя другому вместе с настройками доступа. Почтовые вложения при этой процедуре не переносятся.
- **Интеграция с Р7 по API.** Внутренний редактор документов теперь подключается через API вместо устаревшего протокола *WOPI*. Это открывает пользователям доступ к новым функциям и актуальным исправлениям редакторов Р7 (настройка выполняется через деплоер *VK WorkSpace*).

# **Обновления Доски VK WorkSpace**
Для пользователей веб-версии и десктопного приложения Доски стали доступны инструменты для быстрой навигации и сохранения контента:
- **Экспорт в разные форматы.** Доску теперь можно скачать в виде изображений (PNG, JPG), выгрузить из нее текст в таблицу CSV или сохранить в векторном PDF с высоким качеством печати и поиском по тексту.
- **Дублирование и навигация.** Появилась функция копирования доски со всем содержимым (за исключением комментариев), а также инструмент «Мини-карта» для быстрого обзора и перемещения по рабочему пространству.
